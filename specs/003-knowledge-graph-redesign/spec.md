# Spec: Knowledge 그래프 화면 리디자인 (Obsidian형)

## 사용자 가치

- 프로젝트 지식(보고서·결정·수동 지식·용어·액션·전사)이 어떻게 연결되어 있는지 한 화면에서 탐색한다.
- 회의가 쌓일수록 지식의 구조(클러스터, 허브, 고아 노트)가 시각적으로 드러난다.
- 옵시디언 Graph View와 동일한 조작감: 실시간 물리 시뮬레이션, 노드 드래그, 힘/표시 파라미터 조정, 줌 연동 라벨.

## 확정 사항 (2026-07-25, 사용자 결정)

- 레이아웃: **시안 B Graph-first** — 전역 그래프가 랜딩, 좌측 설정 패널, 우측 노트 프리뷰 슬라이드.
- 노드 디자인: **시안 B 소프트 글로우** — radial gradient 헤일로, 다크 모드 발광, hover 시 증폭.
- 데이터 구조는 옵시디언 모델(Note + 명시적 Link + 백링크)로 이행한다. 백엔드 변경 허용.
- 스타일: Tailwind + 디자인 토큰(tokens.css)만 사용. 신규 화면에서 app.css 의존 금지.

## 범위

### 1단계 (이번 구현)
- `features/knowledge/` 수직 슬라이스: 그래프 화면 전체.
- 기존 `GET /spaces/{id}/knowledge/graph` 응답을 어댑터(`buildGraphView`)로 소화.
- 라우트: `/spaces/:spaceId/knowledge` → 새 그래프 화면, `/knowledge/legacy` → 기존 화면 유지.

### 2단계 (백엔드 협업 필요)
- Note/Link 1급 모델 (data-model.md 참고), 위키링크 파싱, 백링크·언링크드 멘션.
- 로컬 그래프 API(`GET /notes/{id}/graph?depth=`), 전역 그래프 페이지네이션.

## 비범위
- 3D 뷰(시안 검증 완료, 도입 여부는 2단계에서 재평가).
- 노트 편집기(마크다운 에디터)는 별도 스펙으로 분리.

## 권한 (constitution 준수)
- 그래프/상세 조회는 기존 knowledge API 권한 필터를 그대로 사용한다 (권한 선필터 원칙).
- 프론트는 서버가 내려준 노드만 렌더링하며 임의 병합하지 않는다.
