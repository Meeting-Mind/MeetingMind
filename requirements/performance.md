# Performance And Token Targets

성능 문서는 사용자가 이해하기 쉬운 목표 표현을 사용한다. `p95` 같은 용어 대신 `요청 100건 중 95건 이상`으로 표현한다.
Google Sheets 성능지표 시트의 전체 컬럼을 보존한 로컬 스냅샷이다.

## ① AI 응답 성능

### PERF-AI-01 AI 요청 공통 UI

- 분류: AI
- 대상 기능/API: AI 요청 공통 UI
- 측정 기준: 요청 후 화면 피드백 표시 시간
- 프로토타입 목표: 1초 이내
- MVP 목표: 0.5초 이내
- 측정 조건/데이터 규모: 사용자가 질문을 보낸 직후부터 로딩/진행 상태가 보일 때까지
- 실패/대응 기준: 목표 초과 시 버튼을 잠그고 진행 상태와 재시도 안내를 표시한다.
- 우선순위: `P0`
- 관련 요구사항/비고: NFR-UX-03, NFR-PERF-02
