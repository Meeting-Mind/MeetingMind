# Functional Requirements

이 문서는 기능 요구사항 ID와 핵심 요구를 빠르게 찾기 위한 요약 카탈로그다.
전체 우선순위 요구사항의 인수 기준, 조건/권한, 실패/예외, 검증 기준은 `functional-requirements-detail.md`를 함께 확인한다.
